# 台词块对照

## 对照单位

本网站收录 39 部戏剧，以英文原作中的完整角色台词块为阅读单位。台词内部不拆句、不逐句配对。独立舞台指示仍占自己的英文行，序幕、引子与合唱保留为戏剧正文。

中文来自所提供的纪念版原文。匹配结合幕场、角色和整段语义，并允许同一角色的一段译文对应英文中被舞台指示隔开的几个块。这类译文仅显示一次并标出合并对应，不按段落序号机械配对。不同版本的幕场编号不同，不能仅凭编号认定缺文。

中文独有的前言、人物表、编者说明与注释不进入主对照正文；原版戏剧材料可在完整底本入口查阅。不能可靠确定的对应保留英文并标出待核对，不生成替代译文。

## 匹配方法

角色别名按作品核查，先在幕/场上下文中恢复说话回合，再结合本地多语语义向量与角色序列匹配整段。模型为 sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 的固定版本 ONNX 量化模型；长台词分窗计算语义特征，显示时仍保留整段。计算在本地进行，没有把译文上传到外部推断 API。舞台指示单独匹配，避免其移动造成后续台词错位。

## 数据与复现

每个英文块保持原始 ID、全文与顺序。中文对应记录是原文 block ID 加字符范围，显示文字必须与来源完全一致。多个英文块共用的译文不重复计入覆盖。

- `data/alignment-records/`：来源精确的块级对应记录
- `data/aligned-collection/manifest.json`：各剧的英文块、台词块及对应覆盖统计
- `scripts/alignment/build_reader.py`：从既有对应记录构建阅读数据
- `tests/fixtures/speech-turn-fixtures.json`：跨译者、跨版本的困难台词回归案例

运行 `npm run rebuild:alignment` 重建。该步骤无需联网或下载模型。自动对应与经过语义核对的记录分开计数；语义核对由模型代理执行，不等同于人类专家审校。语义相似度是辅助信号，不是正确率。

## 来源结构修复

固定来源存在少量结构标记错误。本次按逐条核查的来源位置修复了 434 处：108 个嵌入台词行的角色提示、320 个被拆开的角色标签、3 个被误标为角色的台词前缀、2 个场次标题及 1 个缺失的 Audley 说话者提示。跨版确认依据随修复记录保存；原始档案不变，所有编号行仍可由正文和来源元数据完整还原。最终为 39,658 个英文块、808 节。

没有将所有制表符、括号或韵文行一概视为角色/舞台边界。中文处理也区别实际舞台动作、戏中戏的独立角色行和台词中的解释性括号。

## 验证范围

检查英文原文逐块、逐字、按顺序保留；中文精确来源和无重复消费；戏剧数量、诗歌排除、共享译文只显示一次；搜索、书签、阅读设置和 Pages 子路径。实际覆盖与最终运行结果在发布前写入验证记录。


## 当前覆盖（2026-10-12）

39,658 个英文块全部保留。33,681 个角色台词块中，32,550 个已有对应（96.64%），覆盖 4,281,905 / 4,509,351 个台词字符（94.96%）。209 个英文块经过模型代理语义核对；其余已对应块仍是自动匹配。含舞台提示在内共有 2,958 个待核块。

为避免罕见角色、段内换角色和舞台说明混入其他角色，675 个高风险自动组未进入发布数据。后来完成的逐组核对以精确来源记录覆盖相应结果。没有把覆盖率当作准确率，也没有把所有未匹配的中文都判定为版本新增内容。
