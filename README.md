# Shakespeare · 莎士比亚全集双语阅读

在英文原作与中文译文之间，慢慢读一场戏。

Shakespeare 是一个简洁的双语阅读网站，收录 39 部戏剧与诗歌作品，包括《哈姆莱特》《麦克白》《李尔王》《仲夏夜之梦》及全部 154 首十四行诗。

## 从一本书开始

- **浏览全集**：按中英文书名或译者寻找作品，也可只看明确署名朱生豪的译作。
- **自由对读**：中英并列、仅英文、仅中文随时切换，两种语言各自选择篇章。
- **找到一句台词**：搜索当前作品的中英文内容与角色名，直接跳到所在篇章。
- **留下阅读痕迹**：收藏喜欢的段落，记住篇章位置，下次继续阅读。
- **按自己的习惯阅读**：调整字号、行距与纸张主题，在电脑或手机上阅读。

打开项目中的 [index.html](index.html) 即可开始。书签和阅读设置保存在当前浏览器，无需注册。

## 关于译本

中文采用所提供的人民文学出版社 2014 年纪念版《莎士比亚全集》，逐篇保留译者署名、注释与图片文字，其中 30 部戏剧明确署名朱生豪。英文主要来自 MIT Shakespeare，并补充 Project Gutenberg 的两部剧作。

中英文按作品并列，篇章可独立选择，尚未逐句对齐。不同译者、版本差异与个别待核实署名均在阅读器中说明。
