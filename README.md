# Shakespeare · 莎士比亚戏剧双语阅读

在英文原作与中文译文之间，慢慢读一场戏。

[在线阅读 →](https://bzy-debug.github.io/shakespeare/)

收录 39 部戏剧，包括《哈姆莱特》《麦克白》《李尔王》《仲夏夜之梦》。按角色的一整段台词对读，中英文随同一幕、同一场前进。

## 从一场戏开始

- **台词对照**：英文在左，中文在右，也可切换单语阅读。台词内部保留完整文字。
- **浏览剧目**：按中英文剧名或译者查找，也可只看明确署名朱生豪的译作。
- **找到一段台词**：搜索当前剧目的中英文内容与角色名，直接跳到所在场次。
- **下次继续读**：收藏段落、记住阅读位置，调整字号、行距与纸张主题。

无需注册。书签和设置保存在当前浏览器。网站只收录戏剧，不包含诗歌集。

## 关于对照与译本

中文采用所提供的人民文学出版社 2014 年纪念版《莎士比亚全集》，其中 30 部戏剧明确署名朱生豪，其余按原书署名展示。英文主要来自 MIT Shakespeare，并补充 Project Gutenberg 的两部剧作。

以英文台词块为对照单位，结合角色、幕场与语义建立对应，不拆分台词内部的句子。不同版本有拆段、合段和舞台指示位置差异；合并对应会标注，不能确认的部分保留英文并提示待核对。译文不补写，中文独有的前言和注释不进入对照正文。当前约 97% 的英文台词字符有对应译文，各剧覆盖不同，其余标记待核；已确认的译本缺文或来源标题会单独说明。
